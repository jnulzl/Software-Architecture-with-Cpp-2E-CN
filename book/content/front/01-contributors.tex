\section*{关于作者}

\textbf{Andrey Gavrilin} 是一位经验丰富的软件工程师，对电脑游戏的热情促使他钻研 C++、Pascal 和汇编语言。他拥有工程学（工业自动化）硕士学位，曾在多个领域工作，这让他深刻认识到高质量软件架构的重要性。他的兴趣包括系统编程、嵌入式开发、游戏编程和电子学。作为一名复古游戏和怀旧计算的爱好者，他喜欢研究旧技术如何为现代系统设计提供借鉴。这些爱好与他的专业工作相辅相成，为 IT 的演进带来创作灵感和全新视角。

\textbf{Adrian Ostrowski} 是一位现代 C++ 爱好者，既关注 C++ 语言本身的发展，也关注用 C++ 写出的高质量代码。作为一名终身学习者，他在 IT 行业以及 C++ 领域拥有十多年的经验，并且始终乐于分享自己的知识。他过去的项目涵盖并行计算、光纤网络，以及为一家商品交易所的交易系统工作。

在业余时间，Adrian 曾与 Piotr 一起推广乐队，还学会了驾驶滑翔机。他喜欢骑自行车、参加音乐活动，以及浏览表情包。

\textbf{Piotr Gaczkowski} 在编程和 DevOps 实践方面拥有十多年的经验，并用自己的技能改善人们的生活。他喜欢为人们遇到的问题构建简单方案、组织文化活动，以及指导同行。Piotr 热衷于把枯燥的工作自动化，并用自己的经验，通过开设课程、撰写有关个人成长和远程工作的文章来分享知识。

他在 IT 行业既做过全职工作，也做过自由职业者，但他真正的热情在于音乐。不在工作中施展技能时，你会发现他在建设社群。

\section*{关于审阅者}

\textbf{Deák} \textbf{Ferenc} 踏入软件开发领域时，编程还意味着从杂志页面上破解晦涩难懂的助记符，再手动录入一台真正的 ICE Felix HC-91 计算机（著名 Sinclair ZX Spectrum 的克隆机）。从这些不起眼的起点出发，他一路穿越技术飞速更迭的浪潮，还曾开心地把设备升级到配有 EGA 显示器的 386。那 16 种颜色给他留下了难以磨灭的印象，让他永远钟情于软件创造这一迷人世界。

多年来，他成长为一名专注于安全与可靠性的软件开发人员，拥有二十多年的经验。他专攻底层系统编程、优化和应用安全性分析，自认为在 C 和 C++ 方面相当精通，同时也熟练掌握 Go、Java、Python 以及各种 Web 技术。他最喜欢的开发领域包括安全、编译器、图形和网络，不过他随时乐于迎接新出现的挑战。他的目标是攻克高难度的软件设计与工程问题，同时不断拓宽自己的专业领域，为不断壮大的开源软件生态贡献力量。在业余时间，他把对技术的热情投入到为各种编程杂志撰写技术文章中。

不坐在键盘前的时候，他通常待在世界第二让他钟爱的地方——厨房操作台旁，在那里他按照特兰西瓦尼亚丘陵、山脉和森林的传统食谱，烹制出（但愿）美味的菜肴。

我要衷心感谢 Packt 社区主动联系并再次邀请我参与这段激动人心的旅程。我也深深感谢各位作者，他们向我介绍了许多我此前并不熟悉的技巧和技术，其中不少开阔了我的视野，并激励我在自己的工作中探索新的方向。

\textbf{Alexei Kondratiev} 是一位关键任务软件与嵌入式系统工程师，在医疗、汽车、高级驾驶辅助系统（ADAS）和航空航天领域拥有 20 多年的经验，专精于低延迟、高吞吐量的并发与异步 C++ 软件开发。他在网络编程与协议、分布式系统、系统与嵌入式编程、故障排查、与开源项目的集成、性能分析与优化方面有扎实的基础。

他目前是 LTA Research 的 C++ 软件开发人员，这是一家航空航天研发公司，负责建造实验性和认证的载人飞艇。在 LTA，他是以下研发型 C++ 项目的负责人：软实时嵌入式 Linux 飞艇氦气气囊体积监测系统、软实时硬件仿真系统，以及面向玻璃座舱电子飞行仪表系统的软实时 Dynon Avionics SkyView HDX 模拟器。
